# ArvanCloud Reseller for WordPress — v1.2.0

افزونه مستقل ریسلری آروان‌کلاد با تمرکز کامل روی محصول **CDN**، کیف پول پیش‌پرداخت و سناریوی قابل ارائه هکاتون.

## نصب

1. فایل ZIP را از مسیر «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. بعد از فعال‌سازی، صفحه خوش‌آمدگویی خودکار باز می‌شود.
3. شناسه و Access Token مربوط به Machine User را وارد کنید یا گزینه «فعلاً رد می‌کنم» را بزنید.
4. افزونه برگه «پنل خدمات ابری» را با بلاک کاتالوگ و پروفایل مشتری می‌سازد؛ در صورت نیاز برگه را از تنظیمات تغییر دهید.
5. برای نمایش امن اطلاعات، هر مشتری باید با حساب وردپرس خودش وارد شود.

## سناریوی دموی پیشنهادی

1. افزونه را فعال و Welcome Screen را نمایش دهید.
2. Onboarding را رد کنید تا حالت Demo بدون کلید واقعی فعال بماند.
3. یک کاربر مشتری بسازید و با آن وارد شوید.
4. کیف پول را با درگاه آزمایشی شارژ کنید.
5. دامنه‌ای مانند `demo.example.com` ثبت کنید؛ Resource ID آزمایشی ساخته و به همان کاربر متصل می‌شود.
6. از پنل ادمین «اجرای محاسبه مصرف» را بزنید و کسر هزینه، لاگ مصرف و تراکنش را نشان دهید.
7. برای نمایش Cron واقعی، اجرای ساعتی `acr_hourly_billing` و تسویه روزانه `acr_daily_settlement` را توضیح دهید.

## قابلیت‌ها

- صفحه Welcome کاملاً RTL و Responsive با مسیر اتصال یا Skip
- ذخیره توکن با رمزگذاری AES-256-GCM و کلیدی مشتق‌شده از salt وردپرس
- نه جدول اختصاصی برای تنظیمات، کاتالوگ، کیف پول، پرداخت، سفارش، سرویس، مصرف، تراکنش و تسویه
- کیف پول اتمیک و دفتر کل غیر وابسته به WooCommerce
- درگاه Mock، ثبت سفارش CDN و Provisioning آنی
- اتصال Resource ID به `user_id` مشتری و ایزوله‌سازی گزارش‌ها
- محاسبه ساعتی مصرف، سهم ریسلر ۰ تا ۲۰٪ و کسر موجودی
- ایمیل هشدار موجودی و Suspend در حالت Demo
- پنل ادمین و پنل مشتری Responsive
- اتصال زنده به endpoint رسمی ساخت CDN با Machine User Token
- داشبورد چندبخشی شامل محصولات ابری، سلامت API، مدیران، سفارش‌ها و فعالیت مالی
- صفحه «محصولات ابری» برای CDN، Cloud Server و Object Storage
- صفحه «داده‌های API» با Inventory نرمال‌شده و بدون نمایش اطلاعات محرمانه
- دریافت دامنه‌های CDN از Machine User API
- دریافت سرورهای ابری از Regionهای قابل تنظیم و نمایش Name، Status، IP و Flavor
- ساخت سرور ابری از پروفایل مشتری با API v3 و مدیریت روشن/خاموش، راه‌اندازی مجدد، تغییر نام، تغییر Flavor، افزایش دیسک، Rescue، بازنشانی رمز و حذف
- دریافت Bucketهای Object Storage از S3 ListBuckets
- صفحه مدیران وردپرس با دسترسی ویرایش هر مدیر
- کش سه‌دقیقه‌ای API و بروزرسانی دستی امن با Nonce
- ساخت خودکار برگه «پنل خدمات ابری» با دو بلاک Gutenberg
- بلاک `acr/product-catalog` برای نمایش محصولات و قیمت‌های فرانت‌آفیس
- بلاک `acr/customer-profile` برای ورود، کیف پول، سفارش و سرویس‌های مشتری
- شورت‌کد جایگزین `[arvan_reseller_products]` برای کاتالوگ
- همگام‌سازی قیمت‌ها از صفحه رسمی قیمت‌گذاری آروان با بازه ۱۵ دقیقه تا هفتگی
- بررسی سلامت منابع مستندات API، قیمت‌ها و شرایط قطع سرویس
- حفظ آخرین کاتالوگ معتبر در صورت قطعی یا تغییر ساختار منبع
- REST endpoint عمومی و فقط‌خواندنی `/wp-json/acr/v1/catalog`
- قفل شدن فرم سفارش تا کافی بودن موجودی کیف پول
- صفحه ادمین «پروفایل مشتریان» با وضعیت نیازمند شارژ/آماده سفارش

## حالت Live و Demo

حالت `demo` به‌صورت پیش‌فرض فعال است و برای ویدئوی هکاتون بدون مصرف حساب واقعی مناسب است. در حالت `live`، ساخت دامنه از API رسمی CDN انجام می‌شود. عملیات Suspend زنده به‌صورت filter تعریف شده تا رفتار دقیق حساب/سیاست محصول بدون حذف ناخواسته سرویس قابل پیاده‌سازی باشد:

برای Inventory سرور ابری، Regionها را در تنظیمات با کاما جدا کنید. Object Storage برخلاف CDN و Cloud Server به اطلاعات جداگانه `S3 Endpoint`، `Access Key` و `Secret Key` نیاز دارد؛ مقادیر محرمانه رمزگذاری می‌شوند و در رابط دوباره نمایش داده نمی‌شوند.

## کاتالوگ فرانت‌آفیس

منابع ثابت همگام‌سازی:

- `https://www.arvancloud.ir/fa/dev/api`
- `https://www.arvancloud.ir/fa/pricing`
- `https://www.arvancloud.ir/fa/legal/service-termination`

قیمت‌ها فقط برای نمایش کاتالوگ از صفحه عمومی استخراج می‌شوند. محاسبات مالی و کسر کیف پول همچنان از موتور حسابداری داخلی افزونه انجام می‌شود تا تغییر HTML یک صفحه عمومی باعث برداشت اشتباه از موجودی مشتری نشود.

WP-Cron وابسته به بازدید سایت است. در محیط production بهتر است cron واقعی سرور هر پنج دقیقه `wp-cron.php` را فراخوانی کند.

```php
add_filter( 'acr_restrict_live_resource', function ( $handled, $resource, $action ) {
    // Call the account-approved ArvanCloud restriction endpoint here.
    return true;
}, 10, 3 );
```

## امنیت

- Nonce برای تمام فرم‌ها
- Capability check برای تمام عملیات ادمین
- sanitize ورودی و escape خروجی
- Query آماده برای اطلاعات وابسته به کاربر
- عدم نمایش مجدد توکن ذخیره‌شده
- حفظ داده‌های مالی هنگام حذف افزونه؛ حذف صریح فقط با تعریف `ACR_REMOVE_DATA_ON_UNINSTALL=true`
